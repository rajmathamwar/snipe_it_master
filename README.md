# Snipe-IT - IT Asset Management System

## 📌 Overview
Snipe-IT is an open-source IT asset management system designed to help organizations track and manage their IT assets, including hardware, software licenses, and accessories.

## 🚀 Features
- Asset Management (laptops, desktops, accessories)
- Software License Tracking
- Asset Check-in / Check-out
- Role-Based Access Control (RBAC)
- Audit Logs & History Tracking
- REST API for integration
- Barcode/QR Code support

## 🛠️ Tech Stack
- Backend: Laravel (PHP)
- Frontend: Blade, Bootstrap
- Database: MySQL
- Server: Apache/Nginx
- Deployment: Docker supported

## ⚙️ Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/snipe/snipe-it.git

Navigate to project folder:

cd snipe-it

Install dependencies:

composer install
Configure .env file

Run migrations:

php artisan migrate

Start server:

php artisan serve
